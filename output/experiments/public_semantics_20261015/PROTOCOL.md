# 事前に固定した実験条件（2026-10-15）

公開5データ（UCI Dry Bean 602、Rice 545、Raisin 850、Occupancy Detection 357、Electrical Grid Stability 471）を使う。各特徴は元の全数値特徴。ID・日時・目的変数は除外し、電力網のstab（ラベルを直接決定する値）も除外する。

5 seed=11,23,37,51,67、ラベル数30/100。通常は層化80/20分割後、訓練が2000行を超えれば層化抽出で2000行に制限。Occupancyは公開者の訓練ファイルと二つのテストファイルの分離を守る。訓練からラベル行を層化抽出、残りはラベルを使わない。MinMaxは訓練のみ、copulaはラベルなし訓練のみから推定。テストによる設定選択なし。

比較：既存VIME列置換、提案Gaussian copula条件付き置換、少数ラベルのみのロジスティック回帰（モデルが違う参考対照）。VIMEはリポジトリ既存実装を変更せず、4層×32、前学習15epoch・半教師300反復、batch64、マスク率0.4、3view、整合性重み1、復元重み2、CPU 1thread。乱数消費が異なるため、分類器学習中のマスク完全一致は保証しない。生成診断は同一アンカーと同一マスク。

相関：訓練内Pearsonの平均絶対値、|r|<0.1の特徴ペア割合と具体的ペアを保存。「低い標本相関」を「独立」と呼ばない。候補選定は意味制約を基準とし、全列が無相関という条件は満たすと仮定しない。

意味制約：形状3データはArea<=ConvexArea+1、MinorAxisLength<=MajorAxisLength、離心率とsqrt(1-(minor/major)^2)の差<=0.01。電力網は|sum(p1:p4)|<=0.01。室内は標準気圧近似の湿り空気式でHumidityRatioの相対誤差<=5%。元データの違反率も測定し、式や許容差の妥当性を確認する。形状の整数画素が小数になる問題はこの診断には含めない。保存した例は列置換で実際に発生した最初の違反行である。

AUC（多クラスはmacro OVR）、Balanced accuracy、Macro-F1を全seed保存。平均と標準偏差、対応差を報告。反復holdoutは重複し、5seedは小数なので探索的比較。勝つデータだけを採用しない。生成の意味的妥当性と分類性能は別々に解釈する。

実行上の調整：元のcopula実装では周辺変換を行・列ごとに呼び出すため遅く、最初の1条件の途中で停止した。分布・乱数の順序・条件付き共分散の式を変えず、周辺変換だけバッチ化するFastGaussianCopulaを実験フォルダに追加。100行×16列（全マスク・マスクなし行を含む）で元実装との出力のビット一致、未置換列の不変性をverify_fast.pyで確認後、全条件を最初から再実行した。中断結果は集計しない。既存の研究実装ファイルは変更していない。
